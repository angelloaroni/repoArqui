# 1.2. Modelo de Negocio

El modelo de negocio del proyecto se representa mediante el **Business Model Canvas (BMC)**. La plataforma funciona como un punto de conexión entre **viajeros que buscan experiencias turísticas locales** y **microoperadores que necesitan canales digitales para promocionar, administrar y vender sus servicios**.

La propuesta combina un enfoque **B2C**, orientado al viajero, con un componente **B2B**, que brinda herramientas de gestión y comercialización a pequeños operadores turísticos.

## Enfoque del modelo

El funcionamiento de la plataforma depende de generar valor para **ambos lados del mercado**:

```text
Microoperadores
       │
       │ Publican experiencias
       │ disponibilidad y horarios
       ▼
┌───────────────────────────┐
│        Plataforma         │
│                           │
│ Descubrimiento            │
│ Recomendaciones           │
│ Disponibilidad            │
│ Reservas                  │
│ Pagos                     │
│ Reputación                │
└───────────────────────────┘
       │
       │ Descubren y reservan
       ▼
    Viajeros
```

Mientras más experiencias y operadores relevantes existan en la plataforma, mayor será el valor para los viajeros. A su vez, mientras mayor sea la cantidad de viajeros utilizando la plataforma, mayor será el incentivo para que nuevos microoperadores publiquen sus servicios.

Este efecto permite que la plataforma evolucione desde un sistema de descubrimiento y reservas hacia un **ecosistema digital para pequeños proveedores turísticos**, incorporando progresivamente herramientas de gestión, analítica y comercialización.
