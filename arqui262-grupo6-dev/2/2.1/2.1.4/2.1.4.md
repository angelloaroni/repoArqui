# 2.1.4. Módulo 4 / Integrante 4 (LOVERA)

## Módulo 4: Descubrimiento, Recomendaciones y Reputación

Este módulo permite a los viajeros encontrar experiencias usando filtros y consultar información del catálogo y de disponibilidad. También presenta recomendaciones iniciales basadas en categorías y valoraciones, y administra reseñas y calificaciones. En el MVP no se contempla personalización basada en seguimiento del comportamiento del usuario.

| ID | Nombre | Historia de Usuario |
|----|--------|---------------------|
| M401 | Búsqueda de experiencias | Como viajero quiero buscar experiencias por nombre o palabras clave para encontrar actividades de mi interés. |
| M402 | Filtrado de experiencias | Como viajero quiero filtrar experiencias por ubicación, fecha, duración, categoría, precio e intereses para encontrar opciones compatibles con mi itinerario. |
| M403 | Consulta de detalles | Como viajero quiero consultar la descripción, duración, ubicación, precio e imágenes de una experiencia para decidir si se ajusta a lo que busco. |
| M404 | Consulta de disponibilidad | Como viajero quiero ver los horarios y cupos disponibles de una experiencia para identificar cuándo puedo reservarla. |
| M405 | Ordenamiento de resultados | Como viajero quiero ordenar los resultados por valoración, precio o duración para comparar las experiencias encontradas. |
| M406 | Recomendación de experiencias | Como viajero quiero recibir sugerencias basadas en categorías y valoraciones para descubrir opciones relevantes sin revisar todo el catálogo. |
| M407 | Registro de reseña y calificación | Como viajero que completó una reserva quiero calificar y reseñar la experiencia para compartir mi opinión con otros usuarios. |
| M408 | Consulta de reputación | Como viajero quiero consultar las calificaciones y reseñas de una experiencia para conocer la opinión de otros participantes antes de reservar. |
| M409 | Cálculo de valoración promedio | Como microoperador quiero que la valoración promedio de mis experiencias se actualice a partir de las calificaciones recibidas para conocer la percepción de los viajeros. |
