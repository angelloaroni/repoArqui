# 0.1.3. Integrante 3 (LEDESMA)

# **Esteban Ledesma**

Estudiante de Ingeniería de Sistemas

## **¿Cuál es mi experiencia en desarrollo de software?**

Tengo experiencia en el desarrollo freelance de tiendas en línea y actualmente participo en la construcción de herramientas internas para **Inca Rail**.

He trabajado en soluciones que van desde **scrapers y aplicaciones internas** hasta **agentes de inteligencia artificial utilizados en producción**.

## **¿Qué tecnologías conozco o domino?**

| Área                  | Tecnologías                   |
| --------------------- | ----------------------------- |
| **Frontend**          | React, TypeScript, JavaScript |
| **Backend**           | Python, FastAPI               |
| **Bases de datos**    | PostgreSQL, SQL Server        |
| **Datos / Analytics** | SQL, BigQuery, GA4            |
| **IA / Agentes**      | LLMs, LangGraph               |
| **Herramientas**      | Git, GitHub, Docker           |

Mi stack preferido actualmente es **React + TypeScript** para frontend y **Python + FastAPI** para backend.

## **¿Cuál es mi expectativa del curso?**

Mi expectativa es profundizar en los conceptos de arquitectura de software para aprender a diseñar y construir sistemas de mayor calidad, escalables, mantenibles y preparados para evolucionar.

También me interesa entender mejor cómo tomar decisiones de arquitectura y evaluar los distintos trade-offs que aparecen al construir sistemas reales.

## **¿Cómo me veo en 10 años?**

Me veo liderando la construcción de productos de software a escala, participando tanto en las decisiones técnicas como en el diseño de soluciones que generen impacto real en los usuarios y en el negocio.

Espero mantener un perfil técnico fuerte y continuar aprendiendo a medida que evolucionen las tecnologías y la industria.
