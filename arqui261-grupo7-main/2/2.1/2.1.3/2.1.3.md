# 2.1.3. Módulo 3 / Integrante 3

# Requisitos Funcionales – Módulo M3: Reservas

El módulo de Reservas constituye el núcleo operativo del sistema. Se encarga de gestionar todo el ciclo de vida de una reserva: desde la búsqueda y disponibilidad del vehículo, hasta la confirmación, modificación, cancelación y devolución. Garantiza una experiencia fluida tanto para propietarios como para arrendatarios.

| ID  | Nombre                      | Historia de Usuario |
|-----|-----------------------------|----------------------|
| RF18 | Búsqueda de vehículos disponibles         | Quiero buscar vehículos disponibles filtrando por fechas, ubicación y tipo de auto. Así, podré encontrar la opción que mejor se adapte a mis necesidades de movilidad. |
| RF19 | Visualización de detalle del vehículo  | Quiero comprobar si mi dirección de correo electrónico ya está registrada. Así, podré evitar crear una cuenta duplicada. |
| RF20 | Creación de reserva     |Quiero seleccionar un vehículo y registrar una reserva indicando las fechas de inicio y fin. Así, podré asegurar el auto que necesito para el período deseado. |
| RF21 | Cálculo automático de costo     | Quiero que el sistema calcule automáticamente el costo total de mi reserva según los días seleccionados y la tarifa del vehículo. Así, podré conocer el monto exacto antes de confirmar. |
| RF22 | Confirmación de reserva           | Quiero recibir una confirmación de mi reserva una vez realizado el pago. Así, tendré la seguridad de que el vehículo quedó reservado a mi nombre. |
| RF23 | Gestión de disponibilidad  | Quiero que el sistema bloquee automáticamente las fechas de un vehículo cuando este tenga una reserva activa. Así, se evitarán conflictos de reservas duplicadas. |
| RF24 | Modificación de reserva           | Quiero poder modificar las fechas de mi reserva antes de que inicie, siempre que el vehículo esté disponible. Así, podré adaptarme a cambios en mis planes sin perder la reserva. |
| RF25 | Cancelación de reserva            | Quiero poder cancelar mi reserva dentro del plazo permitido por la política de la plataforma. Así, podré gestionar imprevistos sin perder todo el monto pagado. |
| RF26 | Historial de reservas            | Quiero consultar el historial de todas mis reservas anteriores y actuales. Así, podré hacer seguimiento de mis alquileres y tener un registro de mis transacciones. |
| RF27 | Notificaciones de reserva            | Quiero recibir notificaciones sobre el estado de mi reserva (confirmada, modificada, cancelada o próxima a iniciar). Así, estaré siempre informado sin tener que ingresar a la plataforma. |
| RF28 | Gestión de reservas del propietario            | Quiero, como propietario, ver y gestionar las reservas activas de mis vehículos. Así, podré aceptar, rechazar o dar seguimiento a cada solicitud de alquiler. |
| RF29 | Devolución y cierre de reserva            | Quiero registrar la devolución del vehículo al finalizar el período de alquiler. Así, el sistema podrá liberar la disponibilidad del auto y habilitar el proceso de calificación. |
