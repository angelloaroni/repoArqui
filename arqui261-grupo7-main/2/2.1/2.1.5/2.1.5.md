# 2.1.5. Módulo 5 / Integrante 5

# Módulo M5: Reseñas y reputación

El módulo de reseñas y reputación permitirá que los usuarios de la plataforma puedan compartir opiniones y calificaciones sobre las experiencias de alquiler realizadas. Este módulo tiene como finalidad incrementar la confianza entre propietarios y conductores, permitiendo visualizar evaluaciones previas y generar un entorno más seguro y transparente. Las reseñas únicamente podrán registrarse cuando una reserva haya finalizado correctamente.

| ID  | Nombre                    | Historia de Usuario |
|-----|---------------------------|----------------------|
| RF39 | Registrar reseña         | Como propietario quiero registrar una reseña luego de finalizar un alquiler. |
| RF40 | Calificar experiencia    | Como usuario quiero calificar la experiencia del servicio recibido. |
| RF41 | Registrar comentario     | Como usuario quiero dejar comentarios sobre la experiencia de alquiler. |
| RF42 | Visualizar reputación    | Como usuario quiero visualizar la reputación de otros usuarios. |
| RF43 | Consultar reseñas        | Como usuario quiero consultar reseñas realizadas por otros usuarios. |
| RF44 | Validar autenticación    | Como administrador quiero que solo usuarios autenticados puedan registrar reseñas para garantizar la seguridad de la plataforma |
| RF45 | Asociar reseña a reserva | Como administrador quiero que las reseñas estén asociadas a reservas finalizadas para evitar reseñas falsas. |
| RF46 | Reportar comentario      | Como usuario o propietario quiero reportar comentarios inapropiados o ofensivos. |
| RF47 | Gestionar historial      | Como usuario quiero visualizar mi historial de reseñas para consultar mis experiencias anteriores. |
| RF48 | Actualizar reputación    | Como usuario quiero que la reputación se actualice automáticamente para visualizar información confiable. |
