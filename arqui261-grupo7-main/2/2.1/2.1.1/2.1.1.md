# 2.1.1. Módulo 1 / Integrante 1

# Requisitos Funcionales – Módulo M1: Usuarios

El módulo de Usuarios se encarga de gestionar el registro, la autenticación, la recuperación de cuenta, los perfiles y el control de roles dentro del sistema. Esto garantiza que los usuarios puedan acceder de manera segura y personalizada a la plataforma.

| ID  | Nombre                      | Historia de Usuario |
|-----|-----------------------------|----------------------|
| RF1 | Registro de usuario         | Quiero registrarme en la plataforma. Para ello, tengo que elegir mi rol y rellenar mis datos personales. Así, podré acceder a las funciones que se adapten a mi perfil de usuario en Driveshare. |
| RF2 | Verificación de correo electrónico  | Quiero comprobar si mi dirección de correo electrónico ya está registrada. Así, podré evitar crear una cuenta duplicada. |
| RF3 | Inicio de sesión seguro     | Quiero iniciar sesión en la plataforma con mi dirección de correo electrónico y mi contraseña. Así, podré acceder de forma segura a mi información. |
| RF4 | Autenticación con OAuth | Como usuario, quiero tener la opción de iniciar sesión con mi cuenta de Google o con las credenciales registradas en la plataforma, para acceder de manera más rápida y conveniente según mi preferencia. |
| RF5 | Gestión de sesión           | Quiero que la plataforma mantenga mi sesión activa durante un período determinado de uso, para no tener que iniciar sesión repetidamente.|
| RF6 | Recuperación de contraseña  | Quiero poder recuperar mi contraseña si la olvido. Así, podré volver a acceder a mi cuenta. |
| RF7 | Gestión de perfil           | Quiero poder editar mi perfil. Así, podré mantener mi información actualizada. |
| RF8 | Verificación de correo electrónico | Quiero verificar mi dirección de correo electrónico mediante un enlace de confirmación enviado a mi correo, para activar mi cuenta y garantizar la seguridad de mi cuenta. |
