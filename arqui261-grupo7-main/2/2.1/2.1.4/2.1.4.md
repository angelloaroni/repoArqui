# 2.1.4. Módulo 4 / Integrante 4

## Modulo de pago

### Requisitos Funcionales

El sistema debe permitir pagos seguros para reservas de vehículos mediante tarjetas y billeteras digitales, calculando automáticamente costos, impuestos y seguros. También debe gestionar depósitos de garantía, distribuir pagos al propietario descontando comisiones, confirmar reservas tras el pago exitoso y realizar reembolsos automáticos en cancelaciones válidas.


| ID    | Nombre                                 | Historia de Usuario |
|-------|----------------------------------------|---------------------|
| RF30  | Procesamiento de pago de reserva       | Como arrendatario, quiero realizar el pago de una reserva utilizando los métodos de pago disponibles por la plataforma, para confirmar mi alquiler de forma rapida y segura. |
| RF31  | Retención de fondos                    | Como arrendatario, quiero que mi pago quede retenido hasta la finalización satisfactoria del alquiler o resolución de incidencias, para contar con respaldo ante inconvenientes. |
| RF32  | Liberación de pago al arrendador       | Como arrendador, quiero recibir automáticamente el pago correspondiente al finalizar el alquiler sin incidencias abiertas, descontando la comisión de la plataforma, para cobrar de forma puntual y transparente. |
| RF33  | Gestión de reembolsos por cancelación  | Como arrendatario, quiero recibir un reembolso cuando cancele una reserva dentro del plazo permitido por la plataforma, para recuperar mi dinero de acuerdo con las condiciones de cancelación vigentes. |
| RF34  | Historial de transacciones             | Como usuario (arrendatario o arrendador), quiero consultar y filtrar mi historial de transacciones por fecha, estado, tipo y monto, para llevar un control claro de mis operaciones financieras. |
| RF35  | Manejo de errores en pagos             | Como arrendatario, quiero recibir mensajes claros cuando un pago falle, indicando el motivo, para poder corregir el problema y reintentar el pago sin riesgo de cobros duplicados. |
| RF36  | Cálculo de comisión de la plataforma   | Como administrador de la plataforma, quiero que el sistema calcule y descuente automáticamente la comisión correspondiente en cada transacción, para registrar correctamente los ingresos de la plataforma. |
| RF37  | Generación de comprobantes             | Como usuario, quiero recibir comprobantes digitales de pagos, reembolsos y liberaciones, para tener constancia de mis operaciones realizadas en la plataforma. |
| RF38  | Almacenamiento de métodos de pago      | Como arrendatario, quiero guardar de forma segura mis métodos de pago para utilizarlos en futuras reservas sin tener que ingresar nuevamente los datos de la tarjeta o billetera digital. |
