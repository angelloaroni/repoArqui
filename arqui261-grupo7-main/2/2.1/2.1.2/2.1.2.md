# 2.1.2. Módulo 2 / Integrante 2

# Requisitos Funcionales – Módulo M2: Catálogo de Vehículos (Detallado)

El módulo de Catálogo de Vehículos permite gestionar la publicación, exploración y administración de vehículos disponibles en la plataforma, facilitando la conexión entre propietarios y usuarios que desean alquilar.

| ID   | Nombre                    | Historia de Usuario |
|------|---------------------------|---------------------|
| RF9  | Registro de vehículo      | Como propietario, se va registrar un vehículo ingresando información detallada como la marca, modelo, año, tipo, número de asientos, transmisión y precio por día, para poder publicarlo en la plataforma y ofrecerlo a los clientes. |
| RF10 | Edición de vehículo       | Como propietario, se modificará la información de mi vehículo en cualquier momento, incluyendo precio, características o descripción, para mantener actualizada  mi oferta. |
| RF11 | Eliminación de vehículo   | Como propietario, se va eliminar un vehículo del catálogo cuando ya no desee ofrecerlo, para evitar que los usuarios intenten reservarlo. |
| RF12 | Visualización de catálogo | Como usuario, se va mostrar un listado de vehículos disponibles con información básica como imagen, precio y características principales, para poder explorar opciones de alquiler fácilmente. |
| RF13 | Carga de imágenes         | Como propietario, quiero subir múltiples imágenes de mi vehículo, para mostrar su estado, diseño y generar mayor confianza en los usuarios. |
| RF14 | Gestión de disponibilidad | Como propietario, definir la disponibilidad de mi vehículo (fechas o estado disponible/no disponible), para controlar cuándo puede ser reservado. |
| RF15 | Búsqueda de vehículos     | Como usuario, quiero buscar vehículos ingresando palabras como marca, modelo o tipo, para encontrar rápidamente opciones que se ajusten a lo que necesito. |
| RF16 | Filtros avanzados         | Como usuario, quiero aplicar filtros como rango de precio, tipo de vehículo, número de asientos, transmisión o disponibilidad, para reducir las opciones y encontrar el vehículo ideal. |
| RF17 | Visualización de detalle  | Como usuario, quiero ver el detalle completo de un vehículo, incluyendo descripción, imágenes, características, precio, disponibilidad y condiciones, para tomar una decisión informada antes de reservar. |
