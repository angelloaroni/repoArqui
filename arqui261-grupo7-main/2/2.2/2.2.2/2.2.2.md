# 2.2.2. Módulo 2 / Integrante 2

### Requisitos de Atributos de Calidad — Módulo 2 (Catálogo)

| Atributo de Calidad | Estímulo | Fuente del Estímulo | Artefacto | Entorno | Respuesta | Medida de Respuesta |
|----------------------|----------|---------------------|-----------|---------|-----------|---------------------|
| Disponibilidad | Un arrendatario consulta autos disponibles | Usuario | Módulo de Catálogo — endpoint de búsqueda | Alta demanda (temporada alta) | El sistema responde sin interrupciones y redirige a servidores alternativos si uno falla | 99.95 % de disponibilidad; recuperación en < 30 s |
| Usabilidad | Un nuevo usuario explora autos por primera vez | Usuario | Interfaz del Catálogo | Primer uso de la aplicación | La interfaz guía al usuario con filtros claros y resultados relevantes | El 90 % de usuarios completa la búsqueda en menos de 3 pasos |
| Rendimiento | Varios usuarios realizan búsquedas simultáneas | Usuarios | Módulo de Catálogo — motor de filtros | Alta concurrencia | El sistema procesa las consultas en paralelo sin rechazar peticiones | Tiempo de respuesta < 2 s por búsqueda; tasa de error < 1 % |
| Escalabilidad | Se incrementa el número de propietarios que publican autos | Propietarios | Módulo de Catálogo y Base de Datos | Crecimiento sostenido | El sistema soporta el aumento sin degradar el rendimiento | Soporta 10,000 publicaciones nuevas/día sin superar 70 % de uso de recursos |
| Seguridad | Un usuario intenta subir fotos maliciosas | Usuario malintencionado | Módulo de Catálogo — gestión de multimedia | Cualquier momento del día | El sistema valida formato y contenido, bloquea archivos sospechosos y alerta al administrador | 100 % de archivos no válidos rechazados antes de almacenarse |
| Mantenibilidad | Se detecta un bug en el motor de búsqueda | Equipo de desarrollo | Módulo de Catálogo | Operación normal | El sistema permite aplicar parches sin interrumpir el servicio | Tiempo de corrección < 24 h; sin afectar búsquedas activas |
