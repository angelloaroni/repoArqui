# 2.2.1. Módulo 1 / Integrante 1

|-----------------|--------------------------------------------------------------------------|-----------------------------------------------------|---------------------------------------------|-------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| Seguridad       | Exposición accidental de la base de datos de contraseñas                | Brecha de seguridad                | Servicio de Almacenamiento de datos  | Operación normal               | Las contraseñas almacenadas están cifradas; ninguna contraseña legible en texto plano                              | 100% de contraseñas cifradas; 0 contraseñas en texto plano en base de datos                     |
| Seguridad       | Un atacante intenta acceder a la cuenta de un usuario mediante múltiples intentos de login con credenciales incorrectas | Usuario malintencionado externo | Módulo de Autenticación (login) | Operación normal | El sistema detecta el patrón de intentos fallidos, bloquea temporalmente el acceso a la cuenta y notifica al usuario legítimo | Bloqueo activado tras ≤ 5 intentos fallidos; cuenta suspendida por ≥ 15 min; notificación al usuario en ≤ 60 s |
| Rendimiento     | 1,000 usuarios intentando iniciar sesión simultáneamente durante hora pico | Usuarios propietarios y arrendatarios              | Módulo de Autenticación (login)             | Alta demanda   | El sistema procesa todas las solicitudes de autenticación sin degradación perceptible                   | Tiempo de respuesta de login ≤ 10 s bajo 1,000 usuarios concurrentes          |
| Mantenibilidad  | Actualización del algoritmo de cifrado de contraseñas (migración a otro cifrado) por nuevos requisitos de seguridad | Equipo de desarrollo / requerimiento de seguridad  | Servicio de Almacenamiento de Credenciales  | Fuera del horario laboral (mantenimiento) | El módulo permite configurar el algoritmo sin cambios en la interfaz pública; las contraseñas antiguas se encriptarán progresivamente al siguiente login | Migración sin downtime; 100% de contraseñas migradas correctamente |
| Disponibilidad | Pérdida temporal de conexión a internet    | Red externa         | API de Autenticación     | Operación normal   | El sistema reintenta la conexión automáticamente                   | Reconexión en ≤ 30 s; sin pérdida de sesiones activas |
