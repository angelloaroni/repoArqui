# 2.2.5. Módulo 5 / Integrante 5

| Atributo        | Estímulo                                                                 | Fuente                                              | Artefacto                                   | Entorno                                   | Respuesta                                                                                                                                              | Medida de Respuesta                                                                                     |
|-----------------|--------------------------------------------------------------------------|-----------------------------------------------------|---------------------------------------------|-------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| Seguridad       | Un usuario intenta registrar una reseña sin haber iniciado sesión | Usuario no autenticado | Módulo de Reseñas | Operación normal | El sistema rechaza la solicitud y solicita autenticación válida antes de permitir registrar la reseña | 100% de intentos no autenticados bloqueados; respuesta en ≤ 2 s |
| Seguridad       | Un usuario intenta publicar una reseña asociada a una reserva inexistente o no finalizada | Usuario malintencionado | Servicio de Validación de Reseñas | Operación normal | El sistema valida la existencia y estado de la reserva antes de permitir publicar la reseña | 100% de reseñas inválidas rechazadas antes del almacenamiento |
| Rendimiento     | Múltiples usuarios consultan reseñas y reputaciones simultáneamente | Usuarios de la plataforma | Servicio de Consulta de Reputación | Alta demanda | El sistema procesa las consultas de reputación sin degradación perceptible en el rendimiento | Tiempo de respuesta ≤ 3 s bajo alta concurrencia |
| Rendimiento     | Usuarios registran múltiples comentarios y calificaciones al mismo tiempo | Usuarios concurrentes | Servicio de Registro de Reseñas | Alta concurrencia | El sistema procesa las solicitudes sin pérdida de datos ni conflictos en la actualización de reputación | Tasa de error < 1%; procesamiento completado en ≤ 5 s |
| Disponibilidad  | El servicio de reputación presenta una falla temporal | Error interno del sistema | API de Reputación | Operación normal | El sistema reintenta automáticamente la operación y mantiene disponible el resto de funcionalidades | Recuperación en ≤ 30 s; disponibilidad ≥ 99.9% |
| Usabilidad      | Un usuario publica una reseña por primera vez sin experiencia previa | Usuario arrendador o arrendatario | Flujo de Registro de Reseñas | Primer acceso desde dispositivo móvil | El sistema presenta formularios claros, validaciones visibles y mensajes comprensibles para completar la reseña sin asistencia | 90% de usuarios completa la reseña sin soporte externo; tiempo promedio ≤ 3 min |
| Mantenibilidad  | Se requiere agregar un nuevo criterio de calificación al sistema de reputación | Equipo de desarrollo | Servicio de Reputación | Fuera del horario laboral (mantenimiento) | El sistema permite incorporar nuevos criterios de evaluación sin afectar otros módulos | Implementación completada en ≤ 6 horas; sin afectar funcionalidades existentes |
| Interoperabilidad | El módulo de reputación necesita validar información de reservas finalizadas | Servicio de Reservas | API de Integración entre módulos | Operación normal | El sistema consulta correctamente la información de reservas y sincroniza los datos necesarios para validar reseñas | 100% de sincronización correcta; tiempo de integración ≤ 3 s |
| Disponibilidad  | Un usuario reporta un comentario ofensivo o inapropiado | Usuario propietario o arrendatario | Módulo de Moderación de Comentarios | Operación normal | El sistema registra el reporte y mantiene operativas las demás funcionalidades del módulo | Registro exitoso del 100% de reportes; confirmación mostrada en ≤ 2 s |
| Modificabilidad | Se requiere actualizar las reglas de cálculo de reputación | Administrador / Equipo técnico | Servicio de Cálculo de Reputación | Tiempo de evolución del sistema | El sistema permite modificar las reglas de cálculo sin rediseñar completamente el módulo | Cambios aplicados afectando menos de 2 componentes |
