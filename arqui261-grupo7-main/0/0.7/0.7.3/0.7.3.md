# 0.7.3. Bases de Datos de Series Temporales

# 1. Definición Conceptual

Las bases de datos de series temporales (Time Series Databases - TSDB) son sistemas especializados en almacenar, consultar y analizar datos asociados a marcas de tiempo (timestamps).

A diferencia de las bases de datos relacionales tradicionales, las TSDB están optimizadas para registrar eventos que ocurren continuamente a lo largo del tiempo, permitiendo realizar consultas históricas, análisis de tendencias y monitoreo de eventos en tiempo real.

Este tipo de bases de datos se utiliza ampliamente en sistemas de monitoreo, IoT, análisis financiero, telemetría y plataformas que generan grandes volúmenes de eventos cronológicos.

Dentro de la plataforma DriveShare, las bases de datos de series temporales podrían emplearse para registrar eventos relacionados con:

- Creación de reservas.
- Confirmaciones y cancelaciones.
- Cambios de disponibilidad de vehículos.
- Métricas de uso de la plataforma.
- Monitoreo de rendimiento de servicios.

Por ejemplo, cada vez que una reserva cambia de estado (Pendiente, Confirmada, Modificada o Cancelada), el sistema podría registrar un evento temporal para posteriormente analizar patrones de comportamiento y demanda.

# 2. Consideraciones Técnicas

Para la investigación se seleccionó **InfluxDB**, una de las bases de datos de series temporales más utilizadas actualmente debido a su alto rendimiento en operaciones de escritura y consulta temporal.

## Instalación de InfluxDB

### Descargar InfluxDB

Ingresar al sitio oficial:

https://www.influxdata.com/downloads/

### Verificar instalación

```bash
influx version
```

Resultado esperado:

```bash
Influx CLI version 2.x.x
```

## Creación del Bucket

Una vez iniciado InfluxDB se crea una organización y un bucket para almacenar los eventos.

- Organización: DriveShare
- Bucket: reservas

## Inserción de Datos

InfluxDB utiliza el formato denominado Line Protocol.

Ejemplo:

```txt
reservas,vehiculo=VH001 estado="confirmada",costo=120.50 1717257600000000000
reservas,vehiculo=VH002 estado="cancelada",costo=0 1717344000000000000
reservas,vehiculo=VH003 estado="confirmada",costo=95.00 1717430400000000000
```

Cada registro almacena:

- Identificador del vehículo.
- Estado de la reserva.
- Costo asociado.
- Marca temporal del evento.

## Consultas

Consultar todas las reservas registradas:

```flux
from(bucket: "reservas")
  |> range(start: -30d)
```

Consultar reservas confirmadas:

```flux
from(bucket: "reservas")
  |> range(start: -30d)
  |> filter(fn: (r) => r.estado == "confirmada")
```

Consultar reservas canceladas:

```flux
from(bucket: "reservas")
  |> range(start: -30d)
  |> filter(fn: (r) => r.estado == "cancelada")
```

## Ventajas

- Optimizadas para consultas basadas en tiempo.
- Alto rendimiento en escritura de eventos.
- Escalabilidad para grandes volúmenes de datos.
- Compresión eficiente de información histórica.
- Integración sencilla con herramientas de monitoreo y dashboards.

## Desventajas

- No reemplazan completamente una base de datos transaccional.
- Requieren aprendizaje de herramientas específicas.
- Algunas operaciones relacionales complejas son más limitadas.

# 3. Demo

La demostración consiste en registrar eventos de reservas dentro de InfluxDB y posteriormente consultarlos mediante consultas temporales.

## Paso 1: Registrar eventos de prueba

```txt
reservas,vehiculo=VH010 estado="confirmada",costo=150.00
reservas,vehiculo=VH011 estado="modificada",costo=180.00
reservas,vehiculo=VH012 estado="cancelada",costo=0
```

## Paso 2: Consultar eventos recientes

```flux
from(bucket: "reservas")
  |> range(start: -1h)
```

## Resultado esperado

| Vehículo | Estado | Costo |
|-----------|---------|---------|
| VH010 | Confirmada | 150.00 |
| VH011 | Modificada | 180.00 |
| VH012 | Cancelada | 0.00 |

## Aplicación en DriveShare

La información almacenada podría utilizarse para:

- Analizar horarios de mayor demanda.
- Identificar vehículos más reservados.
- Obtener estadísticas de cancelaciones.
- Monitorear la evolución de reservas en el tiempo.
- Generar reportes operativos para la plataforma.

---

## Conclusiones

Las bases de datos de series temporales representan una alternativa eficiente para almacenar y analizar eventos históricos generados por una plataforma como DriveShare.

Su utilización permite obtener métricas operativas, monitorear el comportamiento de las reservas, identificar patrones de uso y complementar las bases de datos transaccionales utilizadas por el sistema.
