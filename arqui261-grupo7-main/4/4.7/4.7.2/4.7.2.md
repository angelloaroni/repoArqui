# 4.7.2. Modelo de Coordinación



| ADR | Módulo | Decisión |
|------|---------|---------|
| ADR-02 | M1 - Usuarios | Comunicación síncrona mediante API REST para autenticación, registro, recuperación de contraseña y gestión de perfiles. |
| ADR-02 | M2 - Gestión de Vehículos | Modelo híbrido con REST síncrono para búsquedas, disponibilidad y reservas, y procesamiento asíncrono para notificaciones y eventos secundarios. |
| ADR-02 | M3 - Reservas | Modelo híbrido con operaciones síncronas para validación, creación, modificación y cancelación de reservas, y procesamiento asíncrono para notificaciones y actualizaciones de historial. |
| ADR-02 | M4 - Pagos | Modelo híbrido utilizando REST síncrono para validaciones inmediatas y RabbitMQ para la gestión de eventos de estado. |
| ADR-02 | M5 - Notificaciones | Comunicación síncrona mediante APIs REST. |

Las decisiones adoptadas muestran una tendencia hacia modelos híbridos de coordinación, combinando comunicación síncrona mediante APIs REST para operaciones que requieren respuestas inmediatas y mecanismos asíncronos para tareas secundarias, eventos y notificaciones. Este enfoque permite mantener una experiencia de usuario fluida, reducir tiempos de respuesta y mejorar la escalabilidad general de la plataforma.
