# 4.7.5. Elección de Tecnología


| ADR | Módulo | Decisión |
|------|---------|---------|
| ADR-05 | M1 - Usuarios | React, Express, PostgreSQL, JWT, Google OAuth 2.0, bcrypt, HashiCorp Vault, RSA-2048 OAEP SHA-256 y Docker. |
| ADR-05 | M2 - Catálogo | React, FastAPI, PostgreSQL, MinIO y Docker. |
| ADR-05 | M3 - Reservas | React, FastAPI, PostgreSQL, Redis y Docker. |
| ADR-05 | M4 - Pagos | NestJS, PostgreSQL, TypeORM, BullMQ y Redis. |
| ADR-05 | M5 - Reseñas | NestJS, PostgreSQL y Redis. |

Las tecnologías seleccionadas buscan proporcionar una arquitectura moderna, mantenible y escalable para DriveShare. Tras evaluar distintas alternativas tecnológicas, se decidió adoptar PostgreSQL como principal mecanismo de base de datos, React para las interfaces de usuario y Express como framework backend para la implementación de los servicios de la plataforma.

Adicionalmente, se incorporan tecnologías especializadas como Redis para optimizar el rendimiento mediante mecanismos de caché, HashiCorp Vault para la gestión segura de secretos y credenciales, Google OAuth para ofrecer autenticación externa opcional, MinIO para el almacenamiento de imágenes y archivos asociados a los vehículos, y Docker para facilitar la contenerización, portabilidad y despliegue de la solución.

En el apartado de seguridad de datos, se emplea bcrypt para la protección de contraseñas mediante hashing y RSA-2048 OAEP SHA-256 para el cifrado asimétrico de información sensible. Estas tecnologías complementan la gestión de secretos realizada por HashiCorp Vault y contribuyen a fortalecer la protección de los datos manejados por la plataforma.
