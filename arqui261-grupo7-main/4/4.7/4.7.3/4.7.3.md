# 4.7.3. Modelo de Datos



| ADR | Módulo | Decisión |
|------|---------|---------|
| ADR-03 | M1 - Usuarios | PostgreSQL como base de datos relacional para gestionar usuarios, perfiles y contraseñas protegidas. |
| ADR-03 | M2 - Gestión de Vehículos | Modelo híbrido utilizando PostgreSQL para vehículos, disponibilidad y reservas, y Apache Cassandra para historial de búsquedas y consultas masivas. |
| ADR-03 | M3 - Reservas | Modelo de datos relacional para la gestión de reservas, vehículos, usuarios, estados e historial de operaciones. |
| ADR-03 | M4 - Pagos | Base de datos relacional PostgreSQL. |
| ADR-03 | M5 - Notificaciones | Base de datos relacional PostgreSQL. |


La plataforma adopta un modelo de datos relacional implementado sobre PostgreSQL para sus módulos funcionales.
