# 3.5. Refinamiento de Escenarios


| ID | Atributo de Calidad | Fuente del Estímulo | Estímulo | Artefacto Tecnológico | Entorno | Respuesta del Sistema | Medida de Respuesta |
|----|---------------------|---------------------|-----------|----------------------|---------|----------------------|---------------------|
| ESC-R01 | Seguridad | Usuario malintencionado externo | Intento de acceso no autorizado a cuentas o credenciales de usuarios | Módulo de Autenticación | Operación normal | El sistema protege las credenciales mediante cifrado, bloqueo temporal y validación de autenticidad | 100% de accesos no autorizados bloqueados; bloqueo tras ≤ 5 intentos fallidos |
| ESC-R02 | Disponibilidad | Servicio externo de correo o red | Fallo de servicios asociados a autenticación y recuperación de cuentas | Servicio de Autenticación y Recuperación de Contraseña - Módulo Usuarios | Operación normal | El sistema reintenta operaciones y mantiene la continuidad del acceso | Recuperación ≤ 60 s; disponibilidad ≥ 99.9% |
| ESC-R03 | Usabilidad | Usuario nuevo | Primer uso de funcionalidades de la plataforma | Interfaces de Usuario | Primer acceso | El sistema proporciona validaciones y asistencia contextual para completar tareas exitosamente | Tasa de abandono ≤ 15%; tiempo promedio ≤ 5 min |
| ESC-R04 | Rendimiento | Usuarios concurrentes | Alta concurrencia en procesos de autenticación | Módulo de Login | Hora pico | El sistema procesa solicitudes simultáneas manteniendo tiempos aceptables de respuesta | Tiempo de respuesta ≤ 10 s con 1000 usuarios concurrentes |
| ESC-R05 | Seguridad | Usuario malintencionado | Intento de carga de contenido malicioso en la plataforma | Módulo de Catálogo y Gestión Multimedia | Operación normal | El sistema valida y bloquea archivos potencialmente peligrosos | 100% de archivos sospechosos rechazados antes del almacenamiento |
| ESC-R06 | Rendimiento | Usuarios concurrentes | Elevada cantidad de búsquedas y consultas simultáneas | Servicios de Catálogo, Reservas y Reputación | Alta demanda | El sistema mantiene tiempos de respuesta estables bajo carga | Tiempo de respuesta ≤ 3 s; tasa de error < 1% |
| ESC-R07 | Escalabilidad | Crecimiento del negocio | Incremento sostenido de publicaciones, reservas y transacciones | Infraestructura de la Plataforma | Crecimiento progresivo | La infraestructura distribuye la carga sin degradar el servicio | Utilización de recursos ≤ 70% bajo crecimiento esperado |
| ESC-R08 | Disponibilidad | Infraestructura tecnológica | Fallo parcial de componentes del catálogo o infraestructura | Módulo de Catálogo | Operación normal | El sistema redirige solicitudes y mantiene el servicio disponible | Disponibilidad ≥ 99.95%; recuperación < 30 s |
| ESC-R09 | Disponibilidad | Usuarios concurrentes y propietarios | Solicitudes concurrentes sobre la disponibilidad de vehículos | Módulo de Reservas | Operación normal | El sistema evita inconsistencias y mantiene sincronizada la disponibilidad | 0 reservas duplicadas; actualización ≤ 5 s |
| ESC-R10 | Seguridad | Usuario autenticado malintencionado | Intento de modificar recursos o transacciones sin autorización | APIs de Reservas y Reseñas | Operación normal | El sistema valida permisos y bloquea acciones no autorizadas | 100% de intentos no autorizados rechazados; respuesta ≤ 2 s |
| ESC-R11 | Fiabilidad | Fallo interno del servidor | Fallo durante la ejecución de una reserva | Servicio de Reservas | Operación anormal | El sistema recupera la transacción sin pérdida ni duplicidad de información | Integridad de datos 100%; recuperación ≤ 5 min |
| ESC-R12 | Seguridad | Atacante interno o externo | Intentos de fraude o acceso indebido a información financiera | Módulo de Pagos | Operación normal | El sistema detecta actividades sospechosas y protege los datos sensibles | 100% de pagos fraudulentos bloqueados antes de procesarse |
| ESC-R13 | Disponibilidad | Proveedor de pagos o infraestructura | Caída de servicios de pago o bases de datos financieras | Módulo de Pagos | Alta demanda | El sistema mantiene consistencia y recupera el servicio sin afectar transacciones | Recuperación ≤ 30 s; sin pérdida de datos |
| ESC-R14 | Mantenibilidad | Equipo de desarrollo | Evolución de algoritmos, integraciones o funcionalidades del sistema | Componentes de la Plataforma | Mantenimiento planificado | El sistema permite modificaciones con bajo impacto en los demás componentes | Implementación completada sin interrupción del servicio |
| ESC-R15 | Interoperabilidad | Servicios internos y externos | Intercambio de información entre módulos internos o servicios externos | APIs de Integración | Operación normal | El sistema sincroniza correctamente los datos requeridos para cada operación | 100% de sincronización correcta; tiempo ≤ 3 s |
