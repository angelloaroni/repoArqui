## Componentes transversales

Estos elementos son compartidos por todos los módulos y no pertenecen a uno específico.

| Elemento | Aplicación | Descripción |
| - | - | - |
| `AuthContext` | Frontend | Mantiene el estado global de autenticación del usuario y la información de sesión activa. |
| `ProtectedRoute` | Frontend | Restringe el acceso a rutas protegidas según el estado de autenticación. |
| `RoleRoute` | Frontend | Controla el acceso a funcionalidades específicas según el rol del usuario. |
| `authService.js` | Frontend | Gestiona las operaciones de autenticación y la comunicación con la API. |
| `authMiddleware.js` | Backend | Valida los JWT enviados en las solicitudes protegidas y expone la información del usuario autenticado. |
| `integrations/` | Backend (API REST) | Gestiona la comunicación con Google OAuth, MinIO, Resend y HashiCorp Vault. |
| `integrations/` | Backend (Servicio de Pagos) | Gestiona la comunicación con el Payment Gateway y HashiCorp Vault. |
| `init-vault.js` | Backend | Registra claves RSA y secretos en HashiCorp Vault durante el arranque del entorno Docker. |
| `repositories/` | Backend | Centraliza el acceso a PostgreSQL mediante Sequelize y a Cassandra para consultas masivas del catálogo. |
| `users` | Base de Datos | Tabla principal para autenticación y gestión de usuarios. |

## Flujo de dependencias entre módulos

El módulo de **Autenticación y Gestión de Usuarios** es el punto de entrada al sistema. Una vez autenticado, el usuario puede acceder a las funcionalidades principales de la plataforma.

```text
Autenticación y Gestión de Usuarios
        └── JWT válido
                ├── Gestión de Vehículos
                │       └── Publicación y administración de vehículos
                │
                ├── Gestión de Reservas
                │       └── Solicitud y administración de alquileres
                │
                ├── Gestión de Pagos (Servicio de Pagos independiente)
                │       └── Procesamiento de transacciones asociadas a reservas
                │
                ├── Gestión de Reseñas
                │       └── Calificaciones y comentarios posteriores al alquiler
                │
                └── Dashboard
                        └── Visualización consolidada de información del usuario
```

Las reservas dependen de la existencia de usuarios y vehículos válidos. Los pagos se generan a partir de reservas registradas y son procesados de forma independiente por el Servicio de Pagos. Las reseñas están asociadas tanto al usuario como al vehículo involucrado en una reserva finalizada.
